Entry for the [Famous Last Words: The Funniest Epitaph](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406) bounty on make.fun.

The program writes one line of famous last words — a tombstone epitaph of 150 characters or fewer — to `/output/entry.txt`:

> Do not resuscitate. I have seen the group chat.

Run it with `node main.ts`.
